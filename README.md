# tip-calculator

Two small apps live here:

- **`index.html`** — the original single-file tip calculator. Open it in a browser.
- **`apa-formatter/`** — a web app that takes a school paper (`.docx`, `.txt`, `.md`, …) and returns it formatted to APA 7: title page, page numbers, double spacing, indents, headings, block quotations and a hanging-indent reference page, downloadable as Word or PDF. See [`apa-formatter/README.md`](apa-formatter/README.md) to run it, and [`APA_FORMATTER_PLAN.md`](APA_FORMATTER_PLAN.md) for the longer-term plan (automatic evidence finding and citation generation).
